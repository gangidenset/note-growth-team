# note 記事の構成

## 無料記事（free.md）の目的
信頼を作り、有料記事に興味を持ってもらう。無料でも読者が得をする内容にする。

1. タイトル（具体的なベネフィット。誇大表現なし）
2. 導入: 誰のどんな悩みか
3. 本文: 実際に役立つ情報（出し惜しみしすぎない）
4. 筆者の立場・経験（`【要オーナー記入】` を活用、架空にしない）
5. 有料記事への自然な案内（押し売りしない）

## 有料記事（paid.md）の構成
1. タイトル・価格（meta.json と一致させる）
2. 無料部分: 対象読者、得られること、目次、筆者紹介
3. `<!-- paywall -->`（1つだけ）
4. 有料部分: 具体的手順、テンプレート、チェックリスト、事例（出典付き・実体験は本人記入）
5. まとめ・次の一歩

## 共通ルール
- 数値・事実には出典（市場データID または URL）
- 「必ず」「誰でも」「確実に稼げる」等の断定・保証表現を使わない
- 引用は最小限・出典明記
- ファイル冒頭に YAML front matter は付けない（メタ情報は meta.json に置く）
