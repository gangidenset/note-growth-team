# 進捗の記録と再開

## 更新タイミング
- 1つのタスクが終わったとき
- セッション終了・中断の前
- 承認待ちなどでオーナーの作業待ちになったとき

## docs/progress.md に書くこと
1. **最終更新日時**（タイムゾーン付き）
2. **現在のフェーズ**
3. **完了したこと**（ファイル・コミットへの参照）
4. **進行中のこと**（どこまで進んだか）
5. **残課題**（チェックボックス、担当: AI / オーナー）
6. **次の一手**（そのままコピーして実行できるコマンドや依頼文）
7. **未実施・保留の理由**

## 再開手順
1. `docs/progress.md` を読む
2. `git status` と `git log --oneline -5` で状態を確認
3. フェーズ2以降は `npm run article:status` で記事状態を確認
4. 「次の一手」から再開

秘密情報（キーの値など）は progress.md に書かない。
