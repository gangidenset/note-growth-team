- 版: v0.1（フェーズ1）
- 作成日: 2026-10-23
- 注意: 本書の数値はすべて**計画値・仮定**であり、市場の実測値や実績ではない。実測で検証できたものから順に更新する。

## 1. 目標

| 項目 | 値 |
|---|---|
| 最終目標 | note での月間売上 **50,000円**（税込・手数料控除前の売上ベース） |
| 期間目安 | 立ち上げから6か月以内（仮。初月は売上ゼロも想定） |
| 判断基準 | 毎月の自社実績（noteダッシュボードの値）で評価する |

※「売上」と「手取り」を区別して管理する。手取りは手数料控除後。

## 2. 収益の仕組み（note）

- 収益源の候補: 有料記事（単品）、有料マガジン、メンバーシップ、サポート（チップ）
- MVPでは**単品の有料記事**から始め、反応を見てマガジン・メンバーシップを検討する。

### 手数料の仮定（要確認）
note の手数料は決済方法やプランで異なり、改定されることがある。以下は計画用の**仮置き**であり、フェーズ2開始時に note 公式ヘルプで確認し、確認日をここに記録する。

| 項目 | 仮定値 | 確認日 | 出典 |
|---|---|---|---|
| 手数料合計（決済手数料＋プラットフォーム利用料） | 売上の約15〜20% | 未確認 | note公式ヘルプ（要確認） |
| 振込手数料 | 1回数百円程度 | 未確認 | 同上 |

以下の計算では保守的に「手取り率 80%」を仮定する。

| 500円 | 100本 | 約40,000円 |
| 980円 | 約52本 | 約40,000円 |
| 1,980円 | 約26本 | 約40,000円 |

### ファネル仮説（すべて未検証の仮定）
```
無料記事の閲覧 (PV) → 有料記事ページ閲覧 → 購入
```
- 仮に「無料記事PV→有料記事閲覧」10%、「有料記事閲覧→購入」2〜5% とすると、
  980円で52本売るには 有料記事閲覧 約1,000〜2,600、無料記事PV 約1万〜2.6万/月 が必要。
- これらの転換率は**一般論ベースの仮置き**であり、公開後の自社実績で置き換える。

## 4. 戦略の骨子

1. **テーマ選定は「需要の証拠」と「自分が書ける根拠」の両方で決める**
   - 需要の証拠: 公開されている観測値（類似記事の存在数、価格帯、スキ数、検索結果、Q&Aサイトでの質問の多さ等）。他者の販売数は推測で断定しない。
   - 書ける根拠: オーナーの経験・実績・独自データ。
2. **無料記事で信頼を作り、有料記事で具体的手順・テンプレート・事例を提供する**
3. **小さく出して計測する**: 最初の1か月は価格帯を変えた有料記事を数本出し、自社実績で判断する。
4. **品質と誠実さを優先**: 誇大表現・根拠のない収益保証をしない（景品表示法・note規約対応、信頼の毀損防止）。

## 7. リスクと対策

| リスク | 対策 |
|---|---|
| 需要の読み違い | 小さく出して自社実績で検証、テーマを入れ替える |
| 捏造・誇大表現による信頼失墜/規約違反 | 出典必須スキーマ、品質チェック、承認ゲート |
| 他者コンテンツの模倣・著作権侵害 | 引用ルール遵守、競合記事は構成の観察にとどめ本文を複製しない |
| AI生成文章の均質化 | オーナーの実体験・独自データを必ず盛り込む工程を設ける |
| 手数料・規約の変更 | 確認日を記録し、四半期ごとに再確認 |
| APIコスト超過 | 予算上限を `.env` に設定し、超過前に確認 |
